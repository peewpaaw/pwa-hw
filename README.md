# PWA demo (iOS, local Wi‑Fi) — заявки + push

## Что это
- **PWA** (React + MUI): логин по телефону + код-заглушка **1111**, экран создания заявок **Тип 1/Тип 2** (поля: телефон предзаполнен, ФИО, адрес).
- **Backend** (Node/Express): хранение в **SQLite** (volume), **Web Push** (VAPID ключи в SQLite).
- После создания заявки — **через 10 секунд** отправляется **push** “Заявка принята”.
- Всё запускается через **docker-compose** + **HTTPS** (Caddy internal CA).

## Почему тут нужен “сертификат” на iOS
На iOS (Safari) Service Worker / PWA install / Push работают только на **HTTPS** с **доверенным** сертификатом.  
Так как у нас **только локальная сеть** и **нет домена/Let’s Encrypt**, используем **Caddy `tls internal`** и ставим его CA на iPhone.

## Быстрый старт
### 1) Узнай IP машины в Wi‑Fi

```bash
./scripts/print-ip.sh
```

Допустим, получилось `192.168.1.10`.

### 2) Создай `.env`

```bash
cp .env.example .env
```

В `.env` поставь:
- `PWA_HOST=192.168.1.10` (твой IP из шага 1)
- `JWT_SECRET=что-нибудь-не-пустое`

### 3) Подними контейнеры

```bash
docker compose up --build
```

После запуска будут открыты:
- `http://PWA_HOST` (только чтобы скачать CA)
- `https://PWA_HOST` (само приложение)

## Настройка iPhone для демо (важно)
### 1) Скачай CA сертификат Caddy по HTTP
На iPhone в Safari открой:
- `http://PWA_HOST/caddy-ca.crt`

Сохранится профиль/сертификат.

### 2) Установи сертификат
Дальше:
- **Settings → General → VPN & Device Management** (или “Profiles”) → установить профиль
- Потом **Settings → General → About → Certificate Trust Settings** → включить **Full Trust** для этого CA

### 3) Открой приложение по HTTPS и установи PWA
В Safari:
- открой `https://PWA_HOST` (теперь должно быть без “не доверяем”)
- **Share → Add to Home Screen**
- запусти уже **с иконки** на домашнем экране

### 4) Включи push
В установленном приложении:
- залогинься (любой телефон, код **1111**)
- на экране “Push-уведомления” нажми **“Включить уведомления”**

## Сценарий демо
1) Логин: телефон любой, код `1111`
2) “Включить уведомления”
3) Создать заявку Тип 1 или Тип 2, заполнить ФИО/адрес
4) Через ~10 секунд прилетает push “Заявка принята”

## Данные/персистентность
- SQLite лежит на хосте в `./data/app.sqlite`
- CA Caddy и прочее — в `./caddy_data`
